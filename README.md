# Predicción de Defectos en Producción

Proyecto de Machine Learning Supervisado aplicado al caso de estudio de la empresa manufacturera XYZ Inc.

## Objetivo

Predecir si un lote de producción será defectuoso o no defectuoso utilizando variables relacionadas con el proceso productivo.

## Variables

- Temperatura
- Presión
- Velocidad
- Horas de operación
- Vibración

## Modelos implementados

- Regresión Logística
- Decision Tree
- Random Forest
- Support Vector Machine
- K Nearest Neighbor
- Naive Bayes

## Métricas

Los modelos fueron evaluados mediante:

- Accuracy
- Precision
- Recall
- F1-score
- Matriz de confusión
